# Codex Skills and Agents

Reusable Codex skills and agent instructions collected from the local Codex setup.

## Contents

- `skills/` — SEO, local-model, and orchestration skills. Each skill is self-contained and includes its `SKILL.md` plus supporting files.
- `agents/AGENTS.md` — shared agent instructions.

## Installation

Copy the desired skill directory into your Codex skills directory, and copy `agents/AGENTS.md` to the project or Codex agent configuration location used by your setup.

The files in this directory are configuration and instructions; review them before using them in another project.

## Public bundle scope

This download contains the reusable public skills only. The proprietary keyword scraper, its source code, and its standalone skill are kept private. Use user-provided keyword data or an explicitly approved research source instead.
